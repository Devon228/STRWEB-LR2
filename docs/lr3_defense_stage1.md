### Что показывать по частым вопросам

**1. Анимация при скроллинге. Какое событие?**
`window.addEventListener('scroll', this.onScroll, { passive: true })` — `scroll-animation.js:32`. Внутри `onScroll` стоит `requestAnimationFrame`, чтобы не делать DOM-запись на каждый пиксель (`:53–61`). Формула прогресса — `:66`. При прокрутке вверх `rect.top` растёт, прогресс уменьшается, поэтому анимация обратима. Дополнительно `IntersectionObserver` (`:38`) для появления сцены.

**2. Изменение delay слайдера, только админ.**
Форма владельца — `home.html:85–100`; POST — `views.py:212` (`slider_settings_view`); проверка роли — `if get_user_role(request.user) != Role.OWNER: return HttpResponseForbidden(...)`. Значение `delay` нормализуется в `slider_settings.py:30` (1–60 с), затем попадает в `data-slider-options` (`home.html:41`) и читается `slider.js:26`.

**3. Где сохраняется тема, где стили?**

**7. Что такое `innerHTML`.**
Свойство элемента, строка HTML внутри него. В проекте используется для очистки контейнера (`container.innerHTML = ''` — `contacts.js:500`, `classes-demo.js:115`), а новые узлы строятся через `createElement/appendChild`. ### Если спросят случайную функцию

- `trim()` — убирает пробелы (и пробельные символы) с начала и конца строки, не меняя середину. Используется при валидации: `String(value).trim()` в `contacts.js:37/41`, `classes-demo.js:27`.
- `parseInt(value, 10)` — разбирает строку слева направо до первого нецифрового символа, второй аргумент — система счисления. В `generated-fields.js:237` для `maxlength`.
- `Number.isFinite` — проверяет, что значение является конечным числом (не `NaN`, не `Infinity`); используется в battery API и слайдере.
- `Array.prototype.filter` — создаёт новый массив из элементов, для которых callback вернул `true`; в чекбоксах/поиске/результатах.
- `Set` — коллекция уникальных значений; ID чекбоксов.
- `localeCompare` — сравнение строк по правилам языка (русский порядок, `ё`, числа).
- `FormData` — собирает значения формы по атрибутам `name`.
- `checkValidity()`/`reportValidity()` — встроенная валидация HTML-формы и показ сообщения браузера.

## Этап 3. Карточки

Отдельный файл: `docs/lr3_js_cards.md`. Там разобраны все группы карточек: булевы операции, запятая/приведение типов, `parseInt`, массивы, `toString`, hoisting. Главное правило: **сначала типы, потом операторы**:

1. `&&` и `||` возвращают не `true/false`, а один из операндов; `&&` имеет приоритет выше `||`, вычисление ленивое.
2. Арифметика (`-`, `*`, `/`) приводит операнды к числу; `+` при строке делает конкатенацию.
3. `null` → `0`, `undefined` → `NaN`, `true` → `1`, `[]` → `""`, `[1]` → `"1"`.
4. Объект сравнивается по ссылке; `==` массивов без приведения к примитиву — `false`.
5. `var` поднимается (hoisted) со значением `undefined`; `let/const` — temporal dead zone, обращение до объявления даёт `ReferenceError`.
6. `parseInt` читает цифры с начала строки; если первый непробельный символ не цифра — `NaN`.
