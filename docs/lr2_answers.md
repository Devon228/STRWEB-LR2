## А. Пул вопросов «2 лаба» (из сообщения)

**1. Селекторы, псевдоклассы, псевдоэлементы (показать в коде и на странице).**
Селекторы: элемент `body` (`:64`), класс `.site-nav` (`:692`), атрибутные `input[type="email"]` (`:368`), `a[href^="https://"]` (`:394`), `a[href$=".pdf"]` (`:412`), `a[href*="who.int"]` (`:434`), комбинации `a.read-more[href]` (`:327`), потомок `.site-nav a` (`:332`), дочерний `article > h3` (`:342`), смежные `label + input` (`:349`).
Псевдоклассы: `:link` (`:452`), `:visited` (`:456`), `:hover` (`:460`), `:active` (`:465`), `:focus-visible` (`:469`), `:first-child` (`:476`), `:nth-child` (`:484`), формы `:required`/`:disabled`/`:checked`/`:out-of-range` (`:541–579`).
Псевдоэлементы: `::first-letter` (`:160`), `::first-line` (`:171`), `::before`/`::after` (`:211`, `:244`, `:606`, `:627`), `::selection` (`:584`), `::marker` (`:593`, `:611`).
На странице: меню (наведение/посещённые), каталог (первый/последний пункт), формы (обязательные поля, checked-радио, поле возраста вне диапазона), буквица в новости.

**2. Подключение шрифтов.**
`base.html:17–19` — `<link>` Google Fonts (Montserrat + Roboto). В CSS семейство с запасными: `--font-main` (`:48`), `body { font-family: var(--font-main) }` (`:65`); для сертификата `serif` (`:52`), для реквизитов `monospace` (`:53`).

**3. Медиа-запросы (разные виды, для чего нужны).**
По ширине: `min-width: 1400px` (`:2094`), `max-width: 1024px` (`:2105`), `768px` (`:2133`), `480px` (`:2187`); по высоте: `max-height: 600px` (`:2216`); по ориентации: `orientation: landscape` (`:2241`); по возможностям устройства: `hover: none` (`:2248`), `prefers-reduced-motion` (`:2256`). Меняют число колонок каталога (`:2099`, `:2117`, `:2138`), каркас в колонку (`:2107`), статью в одну колонку (`:2154`).

**4. Настройка текстового фрагмента (всё из условия).**
Красная строка `text-indent: 1.8em` (`:152`); `line-height: 1.65` (`:69`); `text-transform: uppercase/capitalize` (`:186`, `:180`); капитель `font-variant: small-caps` (`:134`, `:177`); интервал между словами `word-spacing` (`:184`), между буквами `letter-spacing` (`:179`); переносы `hyphens: auto` + `overflow-wrap` (`:192–194`); выравнивание `text-align: justify` (`:199`); отступы/поля — `margin`/`padding` у абзацев (`:143`), секций (`:834`) и карточек (`:921`).

**5. Grid Layout, Flexbox — отличия и применение.**
Grid — двумерная сетка: `.catalog-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(230px, 1fr)); gap: 1rem; }` (`:913–918`), также категории и услуги. Flexbox — одномерная раскладка: каркас `.layout` (`:763`), меню (`:692`), карточки новостей (`:1560`), контакты (`.contact-card`, `:1734`).

**6. Настройка стилей summary, details.**
`.faq` (`:1665`), `.faq summary` (`:1680`) — свой маркер `summary::before` (`:1689`), открытое состояние `details[open] summary` (`:1699`), плавные переходы. На странице «Словарь терминов».

**7. Overflow и многоточие.**
Заголовок: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` (`:1600–1603`). Краткое описание: `-webkit-line-clamp: 3` + `overflow: hidden` (`:1607–1611`). Видно в списке новостей.

**8. Виды position и связь с родителем.**
`static` (по умолчанию), `relative` — `.latest-article` (`:1026`), `absolute` — бейдж внутри неё (`:1037`), `fixed` — прелоадер (`:1307`), `sticky` — меню (`:693`). `absolute` считается от ближайшего не-static родителя; без него вёл бы себя как `fixed`.

**9. В чём отличие hidden от display: none.**
`display: none` — элемент убран из потока; атрибут `hidden` делает то же, но семантически (в проекте закреплено `[hidden] { display: none !important; }`, `:656`); `visibility: hidden` — место сохраняется (`:1014`), `opacity: 0` — прозрачен, но участвует в раскладке (`:1015`).

**10. float, clear — в чём суть.**
Вакансии: `.vacancy { float: left; width: calc(50% - 1rem); }` (`:1790`); `clear: both` у нечётных (`:1809`) и у закрывающего элемента `.clear` (`:1813`), чтобы следующий блок не обтекал карточки.

**11. Таблицы: оформление заголовков, удаление двойных границ.**
`border-collapse: collapse` (`:1957`) + `border-spacing: 0` (`:1958`); `caption-side: top` (`:1993`); `thead th` (`:2010`); строки `tbody tr:nth-child(even)` (`:2020`), `:hover` (`:2024`); выравнивание `text-align`/`vertical-align` (`:2033`, `:2006`); таблица по центру `margin: 0 auto` (`:1956`).

**12. Прелоадер — наличие и анимация.**
Внизу страницы: `.preloader` (`:1307`), «пилюля» `.pill` (`:1325`), вращение `@keyframes pill-spin` (`:2321`) с `infinite` (`:1333`). Разметка — `base.html:159–162`, без JS.

**13. Анимация и трансформация, 3D.**
Отличие: `transition` интерполирует между двумя состояниями, `animation` — последовательность keyframes. Свойства `animation` перечислены в `docs/lr2_css_qa.md` (В29). 3D: `perspective` сцены (`:1085`), `rotate3d` лекарства (`:2383`), `perspective + rotateY` логотипа (`:1360`) и партнёров (`:965`). Кривая Безье: `:962`, `:1297`.

**14. Виды градиентов.**
`linear-gradient` (`:80`), `radial-gradient` (`:79`), `conic-gradient` (`:1044`).

**15. Слоистость на сертификате.**
Три слоя: `::before` — водяной знак (`:1383`, z-index 1), `::after` — глянец (`:1397`, z-index 2), `.certificate__content` — текст (`:1406`, z-index 3).

**16. Изменение курсора при наведении на кнопку.**
`cursor: pointer` (`:653`), у заблокированных `cursor: not-allowed` (`:538`), у аббревиатур `cursor: help` (`:276`).

**17. Трансформация логотипа.**
`.company-logo:hover { transform: perspective(700px) rotateY(18deg) rotate(-3deg) scale(1.12); }` (`:1359–1360`), переход `transition` (`:1356`).

**18. Новости в две колонки.**
`.article-content { column-count: 2; column-gap: 2.4rem; column-rule: 2px dotted; }` (`:1648–1657`), при ≤768px — одна (`:2154`).

## Б. Дополнительные вопросы из сообщения

- **Какое значение position всегда с краю браузера?** — `fixed` (прелоадер, `:1307`).
- **Какой position относительно текущего положения?** — `relative` (`:1026`); «залипающий» относительно прокрутки — `sticky` (`:693`).
- **Как сделать анимацию бесконечной?** — `animation-iteration-count: infinite` (в шорткате `infinite`, `:1333`).
- **Где плавающие блоки?** — вакансии, `float: left` (`:1790`).
- **Clear для чего?** — отменяет обтекание float-элементов (`:1809`, `:1813`).
- **Как сделана красная первая буква и отступ?** — `::first-letter` (`:160`) + `text-indent` (`:152`).
- **Схлопывание margin у двух абзацев.** — вертикальные отступы не суммируются, остаётся 1em (`:143`).
- **Где контакты на Flexbox и как ужимаются?** — `.contact-card` (`:1734`): фото `flex: 0 1 150px` (`:1755`), текст `flex: 1 1 260px` (`:1768`), `flex-wrap`; на ≤768px — колонка (`:2176`).
- **Где Grid при уменьшении ширины?** — каталог: 4 → 2 → 1 колонка (`:2099`, `:2117`, `:2138`).
- **Многоколоночная вёрстка где?** — полный текст новости, `column-count: 2` (`:1648`).
