Демонстрация Задача В (Asyncio): Асинхронная подгрузка текстур с сервера во время игры

Изолированная симуляция игрового движка: 15 текстур загружаются конкурентно через asyncio.gather().

Переменная delay задаёт задержку загрузки каждой текстуры, а результат виден в логе ниже.

Для перезапуска нажмите Ctrl + F5. Результат: Успешно загружено: 15 текстур.

Пример кода

async def load_texture(name, delay):
    await asyncio.sleep(delay)
    return name

async def main():
    textures = await asyncio.gather(load_texture("wall", 0.5))
    print(textures)
