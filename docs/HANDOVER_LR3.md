## 1. Что сделано в ЛР3

- **Слайдер (задание 1).** Класс `Slider` в `pharmacy/static/pharmacy/js/slider.js:26`. Пять слайдов на главной (`home.html:38–82`) из картинок ЛР1, у каждого ссылка и подпись. Реализованы `loop`, `navs`, `pags`, `auto`, `stopMouseHover`, `delay`; кнопки «Назад/Далее», счётчик `1/5`, пагинация; при наведении таймер очищается (`clearInterval`), при уходе курсора создаётся заново (`setInterval`).
- **Параметры слайдера для администратора.** Владелец видит на главной форму (`home.html:85–100`), POST идёт в `slider_settings_view` (`views.py:212`); проверка роли — на сервере, не только в шаблоне. Настройки хранятся в сессии (`pharmacy/slider_settings.py`).
- **Тёмная/светлая тема (задание 2).** Кнопка `#theme-toggle` в `base.html:70`, логика — `core.js:103`. Ранний inline-скрипт в `base.html:17–30` применяет тему до отрисовки CSS, чтобы не было вспышки. Выбор хранится в `localStorage` под ключом `pharmacy_theme`. Стили — `style.css:2427` и далее (`html[data-theme="dark"]`).
- **Таблица контактов (задание 3).** Страница `/contacts/` (`contact_list.html`) получает данные из JSON `/contacts/api/` (`views.py:140`), затем клиентский класс `ContactsTable` (`contacts.js:45`) делает сортировку (текст — `localeCompare`, телефон — по цифрам), пагинацию по 3, фильтр по кнопке «Найти», вывод строки в блок под таблицей, добавление сотрудника с валидацией URL/телефона, премирование отмеченных, использование прелоадера ЛР2. Чекбоксы хранятся как `Set` ID и сериализуются в `localStorage` (`pharmacy_contact_selection_v1`), поэтому переживают пагинацию и перезагрузку. Для браузеров без JS в `<noscript>` остались серверные карточки (тест на 10 `<img>` сохранён).
- **Задание 4 (вариант 14, `<input type="tel">`).** Страница `/js-lab/`, секция `generated-fields-task`. Чекбокс создаёт панель атрибутов и первое поле; доступны `name`, `placeholder`, `value`, `pattern`, `required`, `maxlength`, маска телефона, проверка через `checkValidity()`/`validationMessage`, удаление поля, несколько экземпляров, сохранение конфигураций в `localStorage` (`pharmacy_generated_fields_v1`).
- **Пагинация каталога (задание 5).** `/medications/` — по 3 карточки/строки по умолчанию, выбор 3/6/9/12 (`medication_list.html:85–92`), класс `CatalogPaginator` (`catalog.js:12`). Серверный `paginate_by` отключён (`views.py:295`), чтобы клиент видел весь отфильтрованный список.
- **3D/параллакс карточек (задание 6).** `TiltCard` (`catalog.js:124`) пишет CSS-переменные `--tilt-x`, `--tilt-y`, `--shift-x`, `--shift-y`; CSS — `style.css:2921–3041`. Учитывается `prefers-reduced-motion`.
- **Дата рождения (задание 7).** Модальное окно в `base.html:169–193`, логика `core.js:171`. Проверяются будущая дата, возраст, день недели; для несовершеннолетних — `alert` о разрешении родителей. Запрос один раз на вкладку (`sessionStorage`), ссылка «Указать дату рождения» в подвале открывает снова.

## 4. Ограничения

- **Только чистый JavaScript**, без TypeScript, Bootstrap, сборщиков и npm. ES-классы используются только потому, что этого прямо требует задание 8.
- Chart.js лежит локально; интернет для графика не нужен.
- Google Fonts и аватары `ui-avatars.com` требуют сети; при отсутствии сети остаются fallback-шрифты и alt-тексты.
- Battery Status API есть не во всех браузерах (в Firefox его нет); Geolocation требует разрешения, Speech Synthesis зависит от установленных голосов. Это не ошибка приложения.
- Настройки слайдера живут в сессии Django, настройки темы/чекбоксов/сгенерированных полей — в `localStorage` браузера.
- `db.sqlite3`, `media/`, `venv/`, `app.log`, `logs/`, `htmlcov/` в git не входят (см. `.gitignore`).
