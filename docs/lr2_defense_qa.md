## 5. Внешний шрифт: где подключается и зачем несколько в `font-family`

Подключение — в `<head>`: `base.html:17–18` (`preconnect`), `base.html:19` — `<link href="https://fonts.googleapis.com/css2?family=Montserrat…&family=Roboto…&display=swap">`. Параметр `display=swap` показывает текст системным шрифтом, пока грузится веб-шрифт.

```css
/* style.css:48–53 */
--font-main: "Montserrat", "Roboto", "Segoe UI", Arial, sans-serif;
```

Несколько шрифтов — это **стек fallback**: браузер берёт первый доступный слева направо. Если Google Fonts недоступен (офлайн), сработает Segoe UI/Arial, а последний `sans-serif` — обобщённое семейство, которое браузер знает всегда, поэтому текст не «пропадёт». Роли: `--font-main` (body `:67`), `--font-alt` для `option/optgroup` (`:1928`), `--font-serif` для сертификата (`:1377`), `--font-mono` для реквизитов и кода (`:294`, `:306`, `:1516`).

## 10. Где Grid и как сделан перенос на новую строку

```css
/* style.css:913–918 */

    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(230px, 1fr));

```

Grid применён к каталогу на главной (`home.html`, `class="catalog-grid"`), а также к категориям и услугам. ## 11. Позиционирование: `static`, `relative`, `absolute`, `fixed`, `sticky`

- `static` — значение по умолчанию, `top/left` не действуют;
- `relative` — смещается от своего обычного места, остаётся в потоке: карточка последней статьи `.latest-article` (`style.css:1026`) — она объявлена точкой отсчёта для детей;
- `absolute` — позиционируется относительно ближайшего **не-static** предка: бейдж `.latest-article__badge` (`:1037`) внутри `relative`-карточки. Если бы предок был `static`, отсчёт шёл бы от начального содержащего блока (окно/`html`) — и бейдж вёл бы себя как `fixed`;
- `fixed` — всегда относительно **окна браузера**, не движется при прокрутке: прелоадер `.preloader` (`:1307`, `bottom: 0`);
- `sticky` — гибрид: как `relative`, пока не дойдёт до края, затем «прилипает»: меню `.site-nav { position: sticky; top: 0; z-index: 1000 }` (`:692–695`).

Показать: прокрутить страницу — меню остаётся сверху; бейдж «Последняя статья» висит на карточке; прелоадер приклеен к низу окна.

## 12. Функции трансформации в анимации + что значит `left`

В keyframes используются два способа движения:
- **`left`/`top`** — смещение по горизонтали/вертикали у позиционированного элемента. В `customer-walk` (`:2342–2358`) `left` меняется `-18% → 36% → 96% → 114%`: покупатель идёт слева направо, `left` — расстояние от левого края сцены;
- **`transform`** — `rotate3d(1, 1, 0, 540deg)` у лекарства (`:2383`, `:2392`), `rotate(16deg → 0)` при выпрямлении (`:2360–2366`), `translateX/translateY/scale` у названия компании (`:2413–2421`).

Показать сцену на главной: движение покупателя — это `left`, вращение и подлёт лекарства — `transform`.

## 13. `transition` и `animation` — разница

`transition` — плавный переход между двумя состояниями по событию (`:hover`, `:focus`), `@keyframes` не нужны: `transition: transform 0.35s cubic-bezier(…)` у партнёра (`:962`), у логотипа (`:1356`). `animation` — сценарий из ключевых кадров, запускается сам, может повторяться и иметь задержку: `animation: pill-spin 1.6s linear infinite` (`:1333`), `@keyframes` (`:2321`). Коротко: transition — «плавное изменение», animation — «мультфильм по расписанию».

## 14. Сертификат: границы (`border`) и `z-index`

Границы — `border-image` (`style.css:1371`): картинка `cert-border.png` нарезается по 9 частям (`44 round`) и повторяется по периметру; продублировано вендорными префиксами `-webkit-border-image` / `-moz-border-image` (`:2271–2273`). Обычный `border: 26px solid transparent` задаёт толщину рамки.

`z-index` — порядок наложения по оси Z (больше число — выше). У сертификата три слоя: `::before` — водяной знак-печать, `z-index: 1` (`:1383`); `::after` — глянцевый градиент, `z-index: 2` (`:1397`); `.certificate__content` — текст, `z-index: 3` (`:1406`). Работает у позиционированных элементов.

## 17. `float` и `clear`

`float: left` вынимает элемент из потока и прижимает влево, соседи его обтекают: карточки вакансий `.vacancy { float: left; width: calc(50% - 1rem) }` (`style.css:1790`). `clear: both` запрещает обтекание с обеих сторон: у каждой нечётной карточки (`:1809`) — чтобы начинался новый ряд, и у `<p class="clear">` после списка (`:1813`) — чтобы подвал не наезжал на плавающие блоки. Показать: `/vacancies/` — две колонки карточек.

## 18. `border-collapse` — убрать двойные границы и отступы

`border-collapse: collapse` (`style.css:1957`) объединяет границы соседних ячеек в одну общую — двойные линии исчезают; `border-spacing: 0` (`:1958`) убирает зазоры между ячейками в режиме `separate`. Показать: таблица промокодов (`/promos/`) — между ячейками одна тонкая линия, без «коридоров».

## 19. Градиенты: какие есть и какие использовал

Виды: `linear-gradient` (линейный, `:80` — фон сайта, меню, кнопки), `radial-gradient` (радиальный, `:79` — фон body, `:959` — круги партнёров), `conic-gradient` (конический, `:1044` — бейдж «Последняя статья»). Синтаксис: тип + направление/форма + список цветов и стопов; можно задавать проценты, `transparent`, несколько фонов через запятую. Градиент — это `background-image`, поэтому комбинируется с картинками (фон body, `:78–80`).

## 20. Flex: для чего (контакты) и как сделать перенос на новую строку

```css
/* style.css:1734–1738 */
.contact-card { display: flex; flex-wrap: wrap; align-items: center; gap: 1.4rem; }
```

Карточка контакта — Flexbox: фото `flex: 0 1 150px` (`:1755`) не растёт, но сжимается; текст `flex: 1 1 260px` (`:1768`) занимает свободное место. `flex-wrap: wrap` (`:1736`) разрешает перенос на следующую строку, когда элементы не влезают; в медиа-запросе ≤768px карточка вообще становится колонкой (`:2176`). Так же сделано меню: `display: flex` + `flex-wrap: wrap` (`:692–697`) — пункты переносятся на вторую строку на узком экране. Показать: сузить окно — контакты перестраиваются.

## 21. Как расположить элементы в строчку — `inline-block`

`display: inline-block` — элемент ведёт себя как строчный (стоит в строке рядом с другими), но принимает `width`, `height`, `margin` как блочный. В проекте: кнопка «Читать далее» `.read-more` (`style.css:328`), логотип `.company-logo` (`:1350`). Сравнение: `block` — каждый с новой строки, `inline` — в строке, но размеры не задаются, `inline-block` — компромисс. Для целых рядов карточек удобнее `flex`/`grid`.

## 22. `line-height` — что это

`line-height` — расстояние между базовыми линиями соседних строк. Значение без единиц (`1.65`, `style.css:69`) умножается на размер шрифта: 1.65 × 16px ≈ 26px. Реальный «просвет» = `line-height − font-size`, он делится поровну над и под строкой. Заголовкам хватает `1.2` (`:92`). Меньше 1 — строки налезают друг на друга; 1.5–1.7 — комфортно для чтения.

## 23. Капиталь — `font-variant: small-caps`

`font-variant: small-caps` (`style.css:134` — h5, `:178` — имена партнёров, `:870` — заголовки подвала, `:1719` — термины в словаре, `:1995` — подписи таблиц). Строчные буквы отображаются уменьшенными прописными, но регистр в HTML не меняется (в отличие от `text-transform`, который реально меняет регистр). Показать: имена партнёров на главной, подписи таблиц.

## 24. `display: none` — что делает

Полностью убирает элемент из потока: он не отображается и не занимает место (в отличие от `visibility: hidden`, когда место сохраняется). В проекте атрибут `hidden` закреплён правилом `[hidden] { display: none !important }` (`style.css:656`): в форме регистрации `register.html:111` так скрыт блок «Отдел» до выбора роли «сотрудник». Показать: `/register/` — выбрать роль «Сотрудник» → блок появляется (это уже работа JS из ЛР1), по умолчанию он скрыт.

## 25. Что такое `transform-origin`

Точка, относительно которой выполняются `rotate`, `scale`, `skew` (по умолчанию центр элемента — `50% 50%`). В проекте: покупатель — `transform-origin: bottom center` (`style.css:1191`), поэтому наклон `rotate(16deg)` выглядит как «сгорбился» от ног; прилавок — `right center` (`:1112`); логотип — `center` (`:1355`). Показать: если у покупателя origin сместить, он будет наклоняться иначе.

## 26. Функции трансформации — назвать все

2D: `translate(x, y)` / `translateX` / `translateY` — сдвиг; `scale(kx, ky)` — масштаб; `rotate(deg)` — поворот; `skew(x, y)` — наклон; `matrix(...)` — всё сразу. 3D: `translate3d`, `translateZ`, `rotateX/rotateY/rotateZ`, `rotate3d(x, y, z, deg)`, `perspective`. В проекте: `translateY(-6px)` при наведении на карточку каталога (`style.css:931`), `translateY(-2px)` у меню и кнопок (`:727`, `:1905`), `perspective(700px) rotateY(18deg) rotate(-3deg) scale(1.12)` у логотипа (`:1360`), `rotate3d` у лекарства (`:2383`), `rotate` у покупателя (`:2360`).

## 27. `column-count` (новости в две колонки)

```css
/* style.css:1648–1657 */
.article-content {
    column-count: 2;
    column-gap: 2.4rem;
    column-rule: 2px dotted #c7d2fe;
}
```

`column-count` разбивает содержимое блока на указанное число колонок, текст перетекает из левой в правую «как в газете»; `column-gap` задаёт промежуток, `column-rule` — разделительную линию. Применено к полному тексту новости (`news_detail.html:19`, `<div class="article-content">`); при ширине ≤768px остаётся одна колонка (`:2154`). Буквица (`:160`) и выравнивание по ширине (`:199`) дополняют газетный вид. Показать: открыть любую новость.
