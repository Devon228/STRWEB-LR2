## 4. Подключение шрифтов

**В11. Как подключён шрифт из службы и зачем альтернативные?**

```css
/* style.css:48, 65 */
--font-main: "Montserrat", "Roboto", "Segoe UI", Arial, sans-serif;

```

Если сервис недоступен, браузер идёт по списку слева направо и доходит до системного `sans-serif` — сайт не «ломается». `sans-serif` — обобщённое семейство (без засечек), которое браузер подбирает сам; для сертификата используется `serif` (Georgia, `:52`), для реквизитов — `monospace` (`:53`). ## 5. Настройка текстового фрагмента

**В12. Красная строка и красная первая буква.**
Красная строка — `text-indent: 1.8em` (`:152`) у абзацев статей, политики и «О компании»; у первого абзаца отступ снят, потому что там буквица (`:157`). Красную первую букву делает `p:first-of-type::first-letter` (`:160`): `float: left; font-size: 3.4em; color: var(--accent)`. Это два разных приёма: `text-indent` сдвигает первую строку целиком, `::first-letter` стилизует только первую букву.

**В13. Межстрочный интервал (`line-height`).**
`line-height: 1.65` (`:69`) — это расстояние между базовыми линиями соседних строк, выраженное в безразмерном множителе (1.65 × размер шрифта). Реальный «межстрочный просвет» = `line-height − font-size`, он делится поровну над и под строкой:

```
 ┌──────────────────────────┐
 │  Текст строки 1          │  ← верх полулидинга
 │──────────────────────────│  ← базовая линия (baseline)
 │   (просвет = LH − size)  │
 │──────────────────────────│  ← базовая линия строки 2
 │  Текст строки 2          │
 └──────────────────────────┘
 line-height = расстояние между соседними baseline
```

**В14. Капитель (`font-variant`) и `text-transform`.**
Капитель — `font-variant: small-caps` (`:134` для h5, `:177` для имён партнёров, `:1684` для `dt` (`:1718`)): строчные буквы отображаются уменьшенными прописными, но регистр в HTML не меняется. `text-transform` меняет регистр: `uppercase` (`:186`, заголовок сертификата и ссылки меню), `capitalize` (`:180`, имена партнёров — каждое слово с заглавной), есть и `lowercase`.

**В15. Интервалы между словами и символами.**
`word-spacing: 0.4em` (`:184`, заголовок сертификата) — между словами; `letter-spacing` (`:179`, `:718`) — между буквами (кернинг имён партнёров и меню).

**В16. Перенос и разрыв слов.**
`hyphens: auto` + `overflow-wrap: break-word` (`:192–194`) — браузер переносит длинные слова по правилам языка (`<html lang="ru">`), а `wbr` в шаблонах задаёт потенциальные точки переноса. Выравнивание — `text-align: justify` (`:199`) в статьях.

## 7. Grid Layout и Flexbox

**В18. Где Grid и чем он отличается от Flexbox?**
Grid — двумерная сетка (строки и колонки одновременно): каталог `.catalog-grid` (`:913–914`) и списки категорий/услуг.

```css
/* style.css:913 */
.catalog-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(230px, 1fr));
    gap: 1rem;
}
```

Flexbox — одномерная раскладка по главной оси: каркас страницы `.layout` (`:763`), навигация `.site-nav` (`:692`), карточки новостей `.news-card` (`:1560`), контакты `.contact-card` (`:1734`). В контактах фото `flex: 0 1 150px` (`:1755`) — не растёт, но может ужиматься, а текст `flex: 1 1 260px` (`:1768`) растягивается и переносится (`flex-wrap: wrap`). Именно поэтому при сужении окна карточка «дышит»: сначала сжимается текст, затем блок переносится, а в media-запросе ≤768px колонка становится вертикальной (`:2176`).

**В19. Где Grid при уменьшении ширины?**
`@media (max-width: 1024px) .catalog-grid { grid-template-columns: repeat(2, 1fr); }` (`:2117`), при 768px — одна колонка (`:2138`).

## 8. Позиционирование

**В20. Виды `position` и связь с родителем.**
- `static` — значение по умолчанию, смещения не действуют;
- `relative` — смещается относительно своего обычного места, остаётся в потоке: карточка последней статьи `.latest-article` (`:1026`) — она объявлена точкой отсчёта для детей;
- `absolute` — вырывается из потока и позиционируется относительно ближайшего **не-static** родителя: бейдж `.latest-article__badge` (`:1037`) внутри `relative`-карточки. Если бы у карточки не было `position: relative`, бейдж отсчитывался бы от окна/`body`, то есть вёл бы себя как `fixed`;
- `fixed` — всегда «приклеен» к краю **окна браузера** и не движется при прокрутке: прелоадер `.preloader` (`:1307`);
- `sticky` — гибрид: ведёт себя как `relative`, пока не достигнет заданного края, затем «прилипает»: навигация `.site-nav { position: sticky; top: 0; z-index: 1000; }` (`:692–695`). Именно поэтому меню остаётся на экране при прокрутке.

## 9. `hidden` vs `display: none` (и `visibility`/`opacity`)

**В21. В чём разница?**
- `display: none` — элемент полностью удаляется из потока, место не занимает;
- атрибут `hidden` — семантический «скрытый» элемент, по умолчанию браузер сам применяет `display: none`; в проекте это закреплено `[hidden] { display: none !important; }` (`:656`) для блока отдела в форме регистрации;
- `visibility: hidden` — элемент невидим, но **место занимает**;
- `opacity: 0` — элемент прозрачен, но полностью участвует в раскладке и событиях.

В проекте на паре `visibility + opacity` построена ссылка «сайт» у партнёра: `.partner__site` (`:1006`) скрыта, при наведении `.partners .partner:hover .partner__site` (`:1019`) становится видимой с плавным переходом.

## 10. `float` и `clear`

**В22. Где плавающие блоки и зачем `clear`?**
Вакансии: `.vacancy { float: left; width: calc(50% - 1rem); }` (`:1790`). Нечётные карточки начинают новый ряд и запрещают обтекание слева — `.vacancy:nth-child(odd) { clear: both; }` (`:1809`). После списка стоит `<p class="clear">` с `.clear { clear: both; }` (`:1813`) — он «закрывает» обтекание и не даёт подвалу наехать на карточки. `clear` отменяет действие `float` с указанной стороны (`left`, `right`, `both`).

## 13. Прелоадер

**В25. Что такое прелоадер и как он сделан?**

## 14. Анимация и трансформация

**В26. Чем отличается `transition` от `animation`?**
`transition` — «лёгкая версия»: плавно интерполирует изменение свойства между двумя состояниями (например, `:hover`), задаётся у самого элемента (`transition: transform 0.3s ease`). `animation` — последовательность ключевых кадров `@keyframes` с несколькими состояниями, управляется свойствами `animation-name`, `duration`, `timing-function`, `delay`, `iteration-count`, `direction`, `fill-mode`.

**В27. Что означают 0 % и 100 % и как сделать анимацию бесконечной?**
0 % — начальное состояние, 100 % — конечное; между ними можно задавать промежуточные (50 %). Бесконечность — `animation-iteration-count: infinite` (или `infinite` в шорткате, `:1333`). В сцене аптеки ключевые кадры 0/30/55/80/100 % задают маршрут покупателя (`:2342`).

**В28. Какие трансформации бывают и где 3D?**
`translate`, `scale`, `rotate`, `skew`, `matrix`, а также 3D-функции `rotateX/rotateY/rotateZ`, `rotate3d`, `translateZ`; точка отсчёта — `transform-origin`. 3D в проекте: `perspective` на сцене (`:1085`), `rotate3d` у лекарства (`:2383`), `perspective(700px) rotateY(...)` у логотипа (`:1360`) и партнёров (`:965`). Анимация сцены: `customer-walk` (`:2342`), `customer-straighten` (`:2360`), `scarf-fade` (`:2369`), `medicine-fly` (`:2378`), `smile-show` (`:2402`), `name-appear` (`:2413`), моргание `blink` (`:2333`).

**В29. Что можно указать в свойстве `animation` (шорткат)?**
`animation: name duration timing-function delay iteration-count direction fill-mode play-state`. В проекте: `animation: pill-spin 1.6s linear infinite;` (`:1333`), `animation: name-appear 12s cubic-bezier(0.22, 1, 0.36, 1) infinite;` (`:1297`). Функции плавности: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `cubic-bezier(...)`, `steps(...)`. Живая кривая Безье есть также в наведении на партнёра — `transition: … cubic-bezier(0.34, 1.56, 0.64, 1)` (`:962`, лёгкий «отскок»).

## 16. z-index и слоистость сертификата

**В31. Что такое `z-index`?**
`z-index` задаёт порядок наложения элементов по оси Z внутри одного контекста наложения. Большее число — выше в стеке; при равных значениях выше тот, кто в коде позже. Работает только у позиционированных элементов (или flex/grid-детей). Пример — сертификат (`about.html`), три слоя:
1. `.certificate::before` (`:1383`, `z-index: 1`) — водяной знак-печать;
2. `.certificate::after` (`:1397`, `z-index: 2`) — глянцевый градиент;
3. `.certificate__content` (`:1406`, `z-index: 3`) — текст поверх.
Плюс отдельные z-index: бейдж статьи (`:1041`), sticky-меню 1000 (`:695`), прелоадер 1200 (`:1311`).

## 20. overflow, многоточие, списки, скругления, схлопывание

**В35. Как обрезается текст с многоточием?**
Заголовок новости — одна строка: `white-space: nowrap; overflow: hidden; text-overflow: ellipsis` (`:1600–1603`). Краткое описание — несколько строк: `display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden` (`:1607–1611`). Такой же приём — у описания партнёра (`:996`).

**В36. Как оформлены списки?**
`list-style: none` убирает стандартные маркеры (`:603`), затем свои маркеры через `::before` (`:606`) и `::marker` (`:611`). Архив промокодов — с зелёными галочками и красными крестиками (`:611–620`).

**В37. Как задаются скруглённые углы?**
`border-radius`: у кнопок и пилюль `999px` (`:1009`, `:1330`), у круглых партнёров `50%` (`:958`), у карточек `var(--radius)` (`:45`).

**В38. Что такое схлопывание margin?**
Вертикальные `margin` двух соседних блоков не суммируются, а схлопываются: у двух абзацев с `margin-bottom: 1em` между ними будет 1em, а не 2em (`:143`). Поэтому в проекте у абзацев задан только нижний отступ, а расстояния секций регулируются `padding` и `border`, а не суммой внешних отступов.

## 21. Вендорные префиксы

**В39. Что это и где использованы?**
Вендорные префиксы — приставки `-webkit-` (Chrome/Safari), `-moz-` (Firefox), `-ms-` (IE/Edge), `-o-` (Opera) для свойств, которые старые браузеры понимают только с приставкой. В проекте: `-webkit-border-image`/`-moz-border-image` для рамки сертификата (`:2271–2273`), `-webkit/-moz/-ms-transform` (`:2276`), `-webkit/-moz/-o-animation` (`:2284`), `-webkit-column-count` (`:2291`), `-webkit-line-clamp` (`:2297`), `-webkit-hyphens` (`:192`).
